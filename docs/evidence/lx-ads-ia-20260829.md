# 领星广告子系统信息架构实测（2026-08-29）

Owner 在应用内浏览器登录领星 ERP，本会话经 `/adverAuthLogin` SSO 桥进入广告子系统，全程只读浏览（点击仅限导航与页签；一次
「修改」入口被权限分类器拦截后未再尝试）。目的：对照修正本仓库工作台与授权书的
分层与用语。以下均为当日实测所见。

## 1. 层级模型

跨类型统一 6 层，做成平铺页签（活动列表页顶部）：

**广告组合(Portfolio) → 广告活动 → 广告组 → 广告 → 投放 → 用户搜索词**

- 下钻即导航：点活动名 → 该活动的广告组列表（URL 带 campaign id）；点组合名 → 组合详情。
- 活动列表页左栏 = 广告组合树（含「未设置广告组合」桶），点选过滤右侧列表；
  每行都带所属组合徽标。组合名由 Owner 自定，多为系列名。
- 按广告类型各有层级词表（旧版三级页签）：
  - SP：广告活动/广告组/广告位/广告/自动投放/关键词/商品投放/否定词/否定投放/用户搜索词/SP顶级预算
  - SB：广告活动/广告组/广告/广告位/关键词/商品投放/用户搜索词/归因于广告的购买
  - SD：广告活动/广告组/广告/商品投放/受众浏览/匹配的目标
  - ST：广告活动/广告组/广告/受众投放

主导航（左侧）：店铺 / 广告 / 词 / 工具 / 分析 / DSP / 结构 / Beta实时 / 商机 / AMC。
「广告」下：广告组合、全部活动、SP广告、SB广告、SD广告、ST广告、已购商品、操作日志、下载中心。
「工具」下：广告建议、广告抢位、分时策略、自动规则、递增预算、历史工具、告警推送、大促备份。

## 2. 全部活动页（对标本仓库工作台）

- 行内徽标：类型 + 投放方式合并显示（SP[手动] / SP[自动] / SD[vCPM]）。
- 列：勾选、类型、活动名（下行小字 = 所属组合）、服务状态（投放中…）、开始日期、
  预算（**行内可编辑**）、曝光量、点击、CPC、花费、广告订单、ACoS、分析、操作。
- KPI 汇总卡：单击(总和)/花费(总和)/ACoS(平均)/广告销售额(总和) + 「+添加指标」自定义；
  表格首行有「汇总」行。
- 筛选三行：国家-店铺、日期窗（**显式起止、默认今天**）、广告类型、投放类型、组合、
  ASIN/MSKU、状态、服务状态、预算类型、竞价策略、成本类型、标签、负责人、名称模糊；
  另有**筛选模板**（保存筛选组合复用）。
- 该店的活动数量为万级（与本仓库同步 API 报的 enabled_paused 窗口同量级互证）。

## 3. 全部投放页——绩效预分桶（本次最重要的交互发现）

表格上方快捷分类条，按绩效直接分桶（数字为当时实测）：

**全部(N) | 有成交 | 有点击无成交 | 有曝光无点击(N) | 无曝光(N) | 分类明细**

这是运营的真实心智模型：「花了钱没单的」「有曝光没点击的」「根本没曝光的」。
另见行内「建议竞价 $1.36 [1.02–1.70]」——Amazon 建议价+区间随行显示，调价有参照。

## 4. 自动化的呈现（对标授权书）

- **分时策略**：模板化。列表列 = 国家、类型（**分时调广告组合预算 / 分时状态**）、模板名、
  有效状态（生效中/已暂停/已经结束）、创建人、创建时间、操作（应用/复制/修改/删除）、
  **应用的对象**（计数）。Owner 实际在用的模板横跨多个站点。
  模板名由 Owner 自定，多为「店铺缩写+日期」。
- **自动规则**：同样「规则 → 应用到活动/广告组」，列含执行方式、累计优化次数、创建人、来源。
- **广告建议**：三步页签 = 设置目标ACoS（**每广告组一个目标值**，行内可编辑，
  批量套用）→ 获取建议并执行 → 目标跟踪。该店的广告组数量为万级。
  与 DEC-113「结论以目标函数为依据」同构，且落到每对象一个目标值的粒度。

## 5. 用语（含当日「变更公告」弹窗全文要点）

- 菜单改名：店铺数据→店铺、出单时段分析→出单时段、活动管理→广告、全部广告→全部活动、
  OtherASIN 报表→已购商品、SP顶级预算→预算上限、关键词规划→词、出单词库→历史出单词、
  重复关键词报表→重复关键词、ABA热门搜索词→ABA搜索词、ASIN流量反查→反查流量词。
  （领星自己也在把菜单词往短、往运营口语收。）
- 表头改名与口径：销售额→广告销售额；直接/间接销售额 = 广告引流后购买了广告商品/非广告
  商品所产生的广告销售额；直接/间接订单、销量、笔单价同构；最近一次超预算时间→超预算时间。
- 状态用语：**投放中**（不是 enabled）、已暂停、已经结束。

## 6. 对本仓库的直接结论

1. 工作台加**下钻导航**（点活动名 → 广告组层带父过滤 + 面包屑），服务端参数已备。
2. 工作台加**绩效分桶快捷条**（服务端筛选 + 全集计数）。
3. 同步提取 `targeting_type`（四报表 5/6 可得，见 lx-v3-feasibility-20260828.md §1）
   → 行内 [手动]/[自动] 徽标，与领星同款。
4. 状态显示中文化：enabled→投放中、paused→已暂停（领星词汇）。
5. 授权书「运行时段」区对齐领星「分时」用语；作用域带入显示对象名清单（不只计数）。
6. 更远期（未定）：广告组合层、筛选模板、每对象目标 ACoS——按需求另立。
