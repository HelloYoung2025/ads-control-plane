# ADR-001：建控制平面，不分发裸 Provider 凭据

日期：2026-08-28 ｜ 状态：ACCEPTED

## 决定

员工与 AI 客户端不直接持有领星 MCP key / 开放平台 AppSecret。所有访问经公司控制平面：身份网关 → 授权交集 → 提案/审批 → 隔离执行器 → 回读对账 → 审计。

## 依据

- 领星凭据现实（2026-08-28 官方文档核查）：开放平台是超管签发的企业全量单密钥，不可按店铺/模块细分——凭据一旦分发，Provider 侧无任何细分边界可依赖，公司 ACL 是唯一真实边界。
- MCP 客户端控制（Codex enabled_tools、Responses API allowed_tools、注解驱动审批）语义互不对齐，且规范原文明确 tool annotations 是不可信提示——客户端控制只能作纵深，服务端授权是唯一公共分母。
- 直发凭据 = prompt injection 与误操作直通生产写，无审计、无金额边界、无 SoD。

## 后果

- 平台必须自建 RBAC/ABAC、审批、审计（本仓库安全内核）。
- 读通道例外：员工个人的领星 MCP 只读 key 用于个人探索可容忍（其权限=该员工本人 ERP 权限），但不得进入任何自动化链路；平台数据面仍走受控通道。
