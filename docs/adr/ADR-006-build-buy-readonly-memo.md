# ADR-006：写通道立项正当性条件（build / buy / read-only-forever）

日期：2026-08-28 ｜ 状态：PROPOSED——待业务 Owner 签署

## 问题

设计输入把"尽量自动化"当作既定终点；实际上写通道（执行器、审批、对账，约占总工程量大头）是否值得建，从未被论证。

## 三个合法终态

| 选项 | 内容 | 成本/风险 |
|---|---|---|
| read-only-forever | 永久 Gate 1 + L1.5：统一事实 + AI 提案 + Bulk Sheet 人工应用 + 操作日志自动核验闭环 | 零写凭据、零执行器；保留大部分 AI 价值 |
| buy / 复用 | 小额自动化由领星原生自动化规则承载，平台只管"规则配置的提案与审计"；或商用工具（Pacvue/Quartile 类） | 依赖第三方规则引擎的可观察性 |
| build（本方案 Gate 3+） | 自建受控写通道 | 工程量大头；见 handoff 全部执行安全机件 |

**read-only-forever + L1.5 是合法终态，不是失败。**

## 写通道（Gate 3）立项的正当性条件（全部满足才立项）

1. 治理占比达标：经平台治理的变更占比（按操作日志来源归因）达到 Owner 设定阈值——证明平台已被采用而非被绕过；
2. L1.5 闭环率与提案被应用率达标——证明提案质量值得自动执行；
3. 人工应用成本（Bulk Sheet 频次 × 耗时）经测量超过写通道建设与运维的 TCO；
4. 事故成本被量化（错写的最坏损失 × 概率）且 Owner 书面接受；
5. §23.1 写工具合同答案落地（DEC-010 写通道选型已决）。
