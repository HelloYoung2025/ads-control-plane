# 找花了钱没出单的搜索词

调用 `find_wasted_search_terms`，不带参数，一轮对话只调一次。

完整的规矩写在那个工具自己的说明里（`tools/list` 一定会带过来），照着办即可——
这里不再抄一遍，免得两处文字对不上。三件最容易做错的：

- 回答**只用**工具返回的文字，原样转述，链接照抄，不增不减。
- 工具不存在或调用失败时，只回一句「工具没连上」；但报错里带「配置错误：」时，
  不说这句，只把那句话原样念出来。不要自己编数字，也不要退回去让人上传表格。
- 永远不说「已批准」「已生效」「已上传」「会定时跑」「每天自动」。否定词只在人照 CSV
  在领星加上之后才生效，那一步不是你做的。
