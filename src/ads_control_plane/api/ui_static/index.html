目标授权书

授权书是你给 AI 划的活动范围：管哪个店铺的哪些广告、追求什么目标、参数边界在哪、允许在哪些钟点发起、一天最多跑几次。只有人能签发和撤销。

用哪种打法

打法只是帮你把下面的数字填好，签发时上传的仍是完整参数；填完可以在「参数细则」里逐项微调。自定义打法存在这台电脑的浏览器里，换电脑请用下载/导入带走。

2管哪些广告、什么时候干活
这份授权管哪些广告
展开勾选清单

选「只管我勾选的对象」时，作用域外的搜索词根本不进入评估，运行结果里会告诉你过滤掉了多少。在下方「对象工作台」勾选后点「用选中对象签授权书」即可带入。

允许在哪些钟点发起运行

这里设定的是「允许在哪些钟点发起运行」：运行由人在 Codex 等 AI 客户端里发起，本系统不会定时调用 AI； 时段只决定发起时放行还是拒绝。它不会按时段改出价， 也不会给广告设分时策略——分时出价由领星的分时工具负责，本系统不碰。

3节奏与期限
为什么最快只到每小时？

因为再快也读不到新东西。否定词依据的搜索词报告是按天出的，我们从领星读到的又是亚马逊的缓存， 滞后从几分钟到一天不等。设成 10 分钟一次，十次读到的是同一份数据，只会把同一批词反复提十遍—— 多出来的是十份重复工单，不是新信息。所以系统的最快节奏就是每小时，最慢是每周。
